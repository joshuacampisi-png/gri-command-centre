How these numbers were built

So you and your wife can re-run the maths on every future order

One pooled order. Both shipments are merged. All goods = $1,011.20, all freight = $320.00. Each product carries a slice of freight equal to its share of the goods value (multiplier = 1,331.20 ÷ 1,011.20 = ×1.3165), so every "landed/vial" already includes shipping.
  • Landed/vial = (goods cost + freight share) ÷ vials — the true delivered cost of each vial.
  • BAC water. 70 paid vials cost $69.51 landed; you also got 20 free, so the cost spreads over 90 vials = $0.77/vial ($0.99 on paid vials only).
  • Currency. Supplier bills in USD; the P&L converts to AUD using the rate you set — update it to the day you paid.
  • RT30 vs RT60 stay separate — different strengths, different landed cost ($21.59 vs $32.65).
  • Profit / Margin appear once you enter a retail price. The ×4 markup is a placeholder, not advice — set your real shelf prices.
Reconciliation: $993.60 (order 1) + $337.60 (order 2) = $1,331.20 — matches both supplier totals to the cent.
